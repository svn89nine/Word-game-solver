# Word-game-solver
Word-game solver using a trie

Boggle-style solver that searches a letter grid for valid dictionary words.

    Structure: Implement a trie or radix tree

    Baseline: Search candidate words individually or use an unpruned search

    Benchmark: Runtime, number of explored paths, and dictionary size

    Demo: Enter a board and watch the solver highlight found words

Combines algorithms, a clear user-facing application, and easy correctness tests.
